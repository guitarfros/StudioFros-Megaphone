# Changelog

## 0.1.1

- LCD readout shows at most two decimals (trailing zeros dropped).

## 0.1.0

First public version.

- Bullhorn / PA loudspeaker effect: compressor, band-pass, horn resonance (HONK), drive,
  slapback / feedback, loudspeaker noise (button click and burst), mix and output level.
- Two loudspeaker models (MODE I / II).
- 12 factory presets and user presets (save, save as, delete, init).
- Rack-panel interface with the artwork generated with Meta AI.
- VST3 and Standalone for Linux, Windows and macOS (built with GitHub Actions).
