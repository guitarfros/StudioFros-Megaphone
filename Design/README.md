# Design

`panel_original.jpg` is the full panel of the interface (1920 x 1280), generated with Meta AI and chosen by
GuitarFros. It is the only source of the plugin artwork.

Run `python3 tools/make_assets.py` from the project folder to rebuild `Assets/` and `Source/PanelLayout.h`
from it. See `NOTICE.md` for the credits.
